Coordinate all social media workflow. Skills available: content-writer, social-poster, analytics, lead-hunter.

## Weekly Plan (Mondays)

1. Read past analytics from `memory/analytics/`
2. Propose a weekly content calendar:
   - Monday: Educational post
   - Tuesday: Technical tip
   - Wednesday: Industry opinion
   - Thursday: How-to / tutorial
   - Friday: Personal / behind-the-scenes
   - Weekend: Reel or visual content
3. Store plan in `memory/strategy/YYYY-WW.json`
4. Output the plan

## Content Repurposing

Extend each piece of content across formats:

| Original | Repurposed To |
|----------|--------------|
| Blog post | Thread (3-5 posts), Reel script, Carousel |
| Video/Reel | Post summary, Quote graphic |
| Thread | Blog post, Reel, Single post |
| Image | Post with caption, Carousel slide |

Repurposing workflow:
1. Take existing content from `memory/` or user input
2. Use `content-writer` to adapt to each format
3. Use `social-poster` to publish each version
4. Space out posts across days (don't post everything at once)

## Content Mix

- 40% Educational
- 20% Engaging
- 20% Social proof
- 10% Promotional
- 10% Personal

## Platform Priority

1. Facebook (broad reach, connected)
2. Instagram/Reels (visual content)
